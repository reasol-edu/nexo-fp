# Despliegue y operación

Esta parte del manual es para quien **instala, configura y mantiene el servidor** donde se ejecuta
Nexo FP: elegir el modo de despliegue, configurar variables de entorno y correo, programar copias de
seguridad, actualizar de versión y resolver problemas técnicos. Requiere cierta familiaridad con la
línea de comandos; si solo quieres **probar** la aplicación en tu ordenador, empieza por la
[prueba rápida](32-despliegue.md#prueba-rapida-en-tu-ordenador-sin-conocimientos-tecnicos).

| Capítulo | Qué encontrarás |
|----------|-----------------|
| [Instalación y requisitos](31-instalacion-y-requisitos.md) | Los modos de despliegue y sus requisitos |
| [Despliegue](32-despliegue.md) | Guías paso a paso: binario nativo, Docker, Plesk, Ubuntu Server y desarrollo local; variables de entorno |
| [Configuración del correo](33-configuracion-del-correo.md) | SMTP, Gmail y envío en segundo plano |
| [Operación y mantenimiento](34-operacion-y-mantenimiento.md) | Copias de seguridad, cola de mensajes, actualizaciones y protección de datos |
| [Comandos de consola](35-comandos-de-consola.md) | Administración desde la terminal |
| [Resolución de problemas](36-resolucion-de-problemas.md) | Arranque, acceso, correo y sincronización en vivo |

Lo que se configura **desde la aplicación** (cursos, docentes, ajustes y bloqueos) está en la
[parte de administración](20-administracion.md); el uso diario, en la
[guía del profesorado](10-guia-del-profesorado.md).
