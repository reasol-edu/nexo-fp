# Glosario

Términos que se usan a lo largo del manual y dentro de la aplicación.

## Conceptos generales

| Término | Significado |
|---------|-------------|
| **FFEOE** | Fase de Formación en Empresa u Organismo Equiparado: el periodo de formación del alumnado de FP en una empresa. Es el proceso que Nexo FP ayuda a planificar y asignar. |
| **FP / FP dual** | Formación Profesional. En la modalidad dual, parte de la formación se realiza en la empresa, con seguimiento compartido entre centro y empresa. |
| **Séneca** | Sistema de información para la gestión educativa de la Junta de Andalucía. La tramitación oficial de las estancias se realiza en Séneca; Nexo FP refleja su estado. |
| **iSéneca** | Servicio de autenticación asociado a Séneca con el que el profesorado puede iniciar sesión en Nexo FP usando sus credenciales corporativas (ver [Roles y permisos](03-roles-y-permisos.md)). |
| **Multicentro** | Capacidad de alojar varios centros educativos en un mismo servidor con los datos aislados entre sí. |

## Estructura académica

| Término | Significado |
|---------|-------------|
| **Curso académico** | Marco temporal del que cuelga todo en un centro. Solo hay uno **activo** por centro; al cambiarlo, cambia el contexto de trabajo. |
| **Familia profesional** | Agrupación de enseñanzas afines (p. ej. Informática y Comunicaciones), con un jefe/a de departamento. |
| **Enseñanza** | Un ciclo formativo concreto (CFGM, CFGS…) dentro de una familia profesional. |
| **Nivel** | Cada curso de una enseñanza (1.º, 2.º…). |
| **Grupo / Unidad** | Conjunto de estudiantes dentro de un nivel, con tutor/a y docentes asignados. «Unidad» es el nombre que usa Séneca para el grupo. |
| **Estudiante** | Alumno/a matriculado, identificado por su **NIE**. |
| **NIE** | Número de Identificación Escolar que identifica de forma única a cada estudiante. |

## Tejido empresarial

| Término | Significado |
|---------|-------------|
| **Empresa** | Organización colaboradora donde el alumnado realiza la FFEOE. |
| **Centro de trabajo** | Sede o filial concreta de una empresa donde se desarrolla la estancia. |
| **Empleado** | Persona de la empresa que puede actuar como tutor/a de empresa (mentor). |
| **Mentor / Tutor/a dual de empresa** | Empleado/a responsable del seguimiento del estudiante dentro de la empresa. |
| **Representante** | Persona que representa legalmente a la empresa (nombre, DNI y cargo); datos opcionales que aparecen en el informe PDF. |

## Estancias y puestos

| Término | Significado |
|---------|-------------|
| **Estancia** | Conjunto de puestos formativos de una misma enseñanza dentro de un periodo (p. ej. «DAW 2.º, marzo-mayo 2027»). |
| **Puesto formativo** | Una plaza dentro de una estancia: un estudiante + un tutor/a docente + un tutor/a de empresa + un estado. |
| **Tutor/a dual docente** | Profesor/a responsable del seguimiento académico de un puesto. |
| **Estado del puesto** | Fase del ciclo de vida: **Borrador → Pendiente de Séneca → Registrado en Séneca**. |
| **Firmado** | Indica que el convenio del puesto está firmado; solo se habilita cuando el puesto está registrado en Séneca. |
| **Convenio** | Acuerdo que ampara la estancia del estudiante en la empresa. |

## Roles

| Término | Significado |
|---------|-------------|
| **Administrador/a global** | Acceso completo a todos los centros y a la sección de Administración. |
| **Administrador/a de centro** | Responsable de un centro concreto (normalmente el equipo directivo). |
| **Coordinador/a de FP dual** | Gestiona las estancias y puestos de las enseñanzas que coordina. |
| **Jefe/a de departamento de familia profesional** | Gestiona las estancias de las enseñanzas de su familia. |
| **Docente de enlace** | Docente asignado a una o varias empresas; prepara puestos sin estudiante asignado. |
| **Tutor/a de grupo / Docente de grupo** | Consulta las estancias de su enseñanza y los puestos de su alumnado. |

Para el detalle de qué puede hacer cada rol, consulta [Roles y permisos](03-roles-y-permisos.md).
